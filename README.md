# Yash Bansal — Ubuntu 20.04 OS Web Portfolio

Personal portfolio website simulating the Ubuntu 20.04 (Linux) desktop environment, built with **Next.js**, **React**, and **Tailwind CSS**.

![Ubuntu Portfolio](public/themes/Yaru/wallpapers/wall-2.webp)

## 🚀 Overview

- **Window Management**: Draggable, resizable, and minimizable windows.
- **Terminal Emulator**: Interactive bash terminal with custom commands (`whoami`, `about-yash`, `openseek`, `ls`, `cat`, etc.).
- **Applications**:
  - **About Yash**: Profile, projects, experience, skills matrix, and interactive resume viewer.
  - **OpenSeek (AI)**: Browser extension for AI artifact detection.
  - **Visual Studio Code**: Integrated code inspector.
  - **Google Chrome**: In-browser web viewer.
  - **Contact Me (Gedit)**: Direct dispatch messenger.
  - **Spotify & Utilities**: Music player, calculator, and system settings.
- **Responsive**: Dynamic scaling across desktop, tablet, and mobile displays.

---

## 🛠️ Tech Stack

- **Framework**: Next.js (React 18)
- **Styling**: Tailwind CSS & Vanilla CSS
- **Icons & Theme**: Ubuntu Yaru Theme
- **State & Utility**: React Draggable, React GA4, jQuery

---

## 💻 Local Development

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev

# 3. Open in browser
# Navigate to http://localhost:3000
```

---

## 📦 Production Build

```bash
# Build static / production bundle
npm run build

# Start production server
npm start
```
